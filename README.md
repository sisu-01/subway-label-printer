# 써브웨이 라벨 프린터

## 📖 프로젝트 소개
써브웨이에서 재고 관리에 쓰는 라벨들을 더 편하게 프린팅해주는 웹사이트입니다.

### 🎯 프로젝트 목표
1.  **싱글 html**: 싱글 html 파일로 만들어 마치 exe처럼 파일 하나로 실행 가능한 제품 만들기
2.  **프린터 연동**: 라벨용 프린터에 규격을 맞춰서 정상적인 프린트 구현
3.  **실사용 제품 만들기**: 회사에서 만드는 것이 아닌, 내가 직접 주도하여 사람들이 편리하게 사용할 수 있는 제품 만들기.

### CDN의 강력함
CDN으로 React 파일을 로드한 덕분에 nodejs 없이 싱글 html 파일로 내가 원하는 사이트를 완성할 수 있었다.<br/>
만들 것이 간단한 사이트라면 굳이 개발환경을 구성할 필요 없이 CDN으로만 개발 할 수 있다는 것을 알았다.
